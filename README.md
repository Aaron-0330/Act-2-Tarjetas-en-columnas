# Prompt
Crea un código en Flutter/Dart para una app de electrodomésticos llamada 'Hagalo'.

Necesito que la pantalla principal tenga un ListView con 5 tarjetas horizontales modernas. El diseño debe ser: fondo de la app gris muy claro, un AppBar azul fuerte centrado, y las tarjetas blancas con bordes redondeados y una sombra suave.

Cada tarjeta debe tener:

Una rayita azul vertical a la izquierda.

La imagen del producto (usa estas URLs exactas:

Microondas: https://raw.githubusercontent.com/Aaron-0330/Imagenes-para-flutter-6to-I-fecha-11-de-febrero-2026/refs/heads/main/microondas.jfif

Lavadora: https://raw.githubusercontent.com/Aaron-0330/Imagenes-para-flutter-6to-I-fecha-11-de-febrero-2026/refs/heads/main/lavadora.jfif

Licuadora: https://raw.githubusercontent.com/Aaron-0330/Imagenes-para-flutter-6to-I-fecha-11-de-febrero-2026/refs/heads/main/licuadora.jfif

Refrigerador: https://raw.githubusercontent.com/Aaron-0330/Imagenes-para-flutter-6to-I-fecha-11-de-febrero-2026/refs/heads/main/refrigerador.jpg

Tostador: https://raw.githubusercontent.com/Aaron-0330/Imagenes-para-flutter-6to-I-fecha-11-de-febrero-2026/refs/heads/main/tostador.webp)

A la derecha de la imagen, pon el nombre del producto en azul fuerte y el precio con un icono de signo de pesos en verde.

Usa un nivel de programación básico-intermedio pero que se vea muy limpio y profesional.
